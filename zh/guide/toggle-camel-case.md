# 切换命名格式

可以识别的格式

- camelCase
- snake_case
- CamelCase
- SNAKE_CASE
- kebab-case
- space case
- Camel Case

可以将上面识别的格式一键转为下面的格式

- camelCase
- snake_case
- CamelCase
- SNAKE_CASE
- kebab-case
