# Toggle Camel Case

Recognizable formats

- camelCase
- snake_case
- CamelCase
- SNAKE_CASE
- kebab-case
- space case
- Camel Case

The format identified above can be converted to the following format with one click

- camelCase
- snake_case
- CamelCase
- SNAKE_CASE
- kebab-case
